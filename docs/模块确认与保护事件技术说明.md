# 模块确认与保护事件技术说明

## 1 适用范围

适用对象：

```text
STM32F407三电机机械臂模块
CAN 2.0B
500 kbps
扩展帧
数据帧
```

当前部署结构：

```text
1块F407 = 1个机械臂 = 3个电机
5个机械臂 = 1组 = 15个电机
所有F407烧录同一份固件
```

组内AXIS映射：

| 机械臂位置 | 本臂电机 | 占用AXIS |
|---:|---|---|
| 机械臂1 | 电机1~3 | 1~3 |
| 机械臂2 | 电机1~3 | 4~6 |
| 机械臂3 | 电机1~3 | 7~9 |
| 机械臂4 | 电机1~3 | 10~12 |
| 机械臂5 | 电机1~3 | 13~15 |

## 2 上电模块确认

### 2.1 接收UID宣告

机械臂每次上电后进入未绑定状态，周期发送：

```text
ID范围：0x15BC0080~0x15BC00BC
DLC：8
DATA：设备类型 + UID低56位
```

实测示例：

```text
ID   = 0x15BC00A4
DLC  = 8
DATA = 01 52 50 06 00 20 00 49
```

解析：

```text
byte0    = 01，设备类型
byte1..7 = 52 50 06 00 20 00 49，UID低56位
```

绑定帧使用数据场中的UID56：

```text
52 50 06 00 20 00 49
```

### 2.2 绑定组号和臂位

绑定命令：

```text
ID：0x15BC0020
DLC：8
DATA：UID低56位 + 绑定字节
```

绑定字节：

```text
(SEG << 3) | (ARM - 1)
```

第1组机械臂1示例：

```text
SEG=0
ARM=1
绑定字节=(0 << 3) | 0 = 0x00
```

完整命令：

```text
ID   = 0x15BC0020
DLC  = 8
DATA = 52 50 06 00 20 00 49 00
```

### 2.3 组号确认

绑定成功后，模块回传：

```text
ID：0x15BC0050
DLC：8
DATA：UID低56位 + ((SEG << 4) | Result)
```

第1组绑定成功：

```text
ID   = 0x15BC0050
DATA = 52 50 06 00 20 00 49 00
```

最后字节解析：

```text
高4位0 = SEG=0，第1组
低4位0 = Result=0，绑定成功
```

### 2.4 臂位确认

```text
ID：0x15BC0060
DLC：8
DATA：UID低56位 + ((ARM << 4) | AxisBase)
```

第1组机械臂1：

```text
ID   = 0x15BC0060
DATA = 52 50 06 00 20 00 49 11
```

最后字节解析：

```text
高4位1 = 机械臂1
低4位1 = 起始AXIS=1
```

`0x15BC0060`是模块回复帧，上位机只能接收，不能再次发送。

### 2.5 可选状态查询

请求：

```text
ID：0x00000020
DLC：4
DATA：12 34 56 78
```

第1组正常应答：

```text
ID   = 0x00002060
DLC  = 8
DATA = 01 00 11 07 07 03 56 78
```

解析：

```text
01      协议版本1
00      SEG=0，第1组
11      机械臂1，起始AXIS=1
07      电机1、2、3都存在
07      电机1、2、3都就绪
03      已绑定并允许运动
56 78   请求Token低16位
```

## 3 运动命令应答

第1组机械臂1：

```text
电机1 ACK：0x04802154
电机2 ACK：0x04802254
电机3 ACK：0x04802354
```

数据格式：

```text
byte0 = AckMsg
byte1 = Result
byte2 = Detail
```

Result定义：

```text
0 = 接受
1 = 轴忙
2 = 组号/臂位未绑定
3 = 参数越界
4 = 轴超位故障锁存
5 = 急停锁存
```

## 4 运动完成与位置回传

### 4.1 停止通知

```text
ID = 0x08C02184
   + (SEG << 18)
   + ((AXIS - 1) << 8)

DLC = 2
```

数据：

```text
byte0 = StopReason
byte1 = 停止时输出档位
```

常用StopReason：

```text
1 = 正常到位
2 = 急停
4 = 限位/超位
```

正常到位：

```text
DATA=01 00
```

急停：

```text
DATA=02 00
```

超位：

```text
DATA=04 00
```

### 4.2 到位通知

```text
ID = 0x08C02180
   + (SEG << 18)
   + ((AXIS - 1) << 8)

DLC = 8
```

数据格式：

```text
byte0..3 = 实际位置，int32
byte4..5 = PosError，int16
byte6    = StatusBits
byte7    = Flags
```

轴1、轴2位置单位：

```text
0.01°
```

轴3位置单位：

```text
0.01 mm
```

### 4.3 位置反馈

```text
ID = 0x04802140
   + (SEG << 18)
   + ((AXIS - 1) << 8)

DLC = 4
```

第1组机械臂1：

```text
电机1：0x04802140
电机2：0x04802240
电机3：0x04802340
```

## 5 相对运动与超位保护

### 5.1 相对运动规则

相对命令不受固定的绝对起点限制：

```text
目标位置 = 运动开始时当前编码 + 相对角度对应编码
```

例如当前位置3°，发送相对正转180°：

```text
正常目标 = 3° + 180° = 183°
```

该命令允许执行。

### 5.2 相对超位余量

| 轴 | 本次目标允许超出量 |
|---|---:|
| 电机1 | 10° |
| 电机2 | 10° |
| 电机3 | 1 mm |

3°位置发送相对180°：

```text
正常目标：183°
保护阈值：183° + 10° = 193°
```

相对本次运动起点超过190°时触发保护。

### 5.3 超位触发结果

```text
立即PWM=0
方向脚PC0~PC5拉低
StopReason=4
上报限位事件
锁存对应轴故障
后续该轴运动返回Result=4
```

### 5.4 限位事件

```text
ID = 0x08C02190
   + (SEG << 18)
   + ((AXIS - 1) << 8)

DLC = 2

DATA=01 00 -> 上限位
DATA=02 00 -> 下限位
```

第1组机械臂1：

```text
电机1停止：0x08C02184
电机1限位：0x08C02190

电机2停止：0x08C02284
电机2限位：0x08C02290

电机3停止：0x08C02384
电机3限位：0x08C02390
```

### 5.5 单轴故障回传汇总

当前单轴故障由超位保护触发，一次超位会发送：

```text
1帧停止事件
1帧限位事件
```

通用事件ID：

```text
停止事件：
ID = 0x08C02184 + (SEG << 18) + ((AXIS - 1) << 8)
DLC=2
DATA=04 00

限位事件：
ID = 0x08C02190 + (SEG << 18) + ((AXIS - 1) << 8)
DLC=2
DATA=01 00 上限位
DATA=02 00 下限位
```

协议中的轴故障事件：

```text
ID = 0x08C02188 + (SEG << 18) + ((AXIS - 1) << 8)
DLC=6
```

当前固件已关闭编码器无进展和反向运动判断，因此不会主动发送 `0x08C0xx88`。当前实际超位故障使用停止事件 `0x08C0xx84` 和限位事件 `0x08C0xx90`。

第1组所有AXIS对应的事件和复位ID：

| AXIS | 停止事件 | 限位事件 | 故障复位ID | 复位ACK |
|---:|---|---|---|---|
| 1 | `0x08C02184` | `0x08C02190` | `0x04402114` | `0x04802154` |
| 2 | `0x08C02284` | `0x08C02290` | `0x04402214` | `0x04802254` |
| 3 | `0x08C02384` | `0x08C02390` | `0x04402314` | `0x04802354` |
| 4 | `0x08C02484` | `0x08C02490` | `0x04402414` | `0x04802454` |
| 5 | `0x08C02584` | `0x08C02590` | `0x04402514` | `0x04802554` |
| 6 | `0x08C02684` | `0x08C02690` | `0x04402614` | `0x04802654` |
| 7 | `0x08C02784` | `0x08C02790` | `0x04402714` | `0x04802754` |
| 8 | `0x08C02884` | `0x08C02890` | `0x04402814` | `0x04802854` |
| 9 | `0x08C02984` | `0x08C02990` | `0x04402914` | `0x04802954` |

### 5.6 超位故障复位

```text
ResetID = 0x04402114
        + (SEG << 18)
        + ((AXIS - 1) << 8)

DLC = 1
DATA = 01
```

第1组机械臂1：

```text
电机1：0x04402114
电机2：0x04402214
电机3：0x04402314
```

正常复位应答：

```text
电机1 ACK：0x04802154 DATA=05 00 00
电机2 ACK：0x04802254 DATA=05 00 00
电机3 ACK：0x04802354 DATA=05 00 00
```

通用复位应答ID：

```text
0x04802154 + (SEG << 18) + ((AXIS - 1) << 8)
```

复位成功后：

```text
该轴Result=4清除
普通运动命令可再次执行
其他轴的故障锁存不受影响
```

## 6 模块急停

模块急停命令：

```text
ID = 0x00000008 + (SEG << 18)
DLC = 1
DATA = 01
```

示例：

```text
第1组：0x00000008
第2组：0x00040008
```

触发结果：

```text
本F407三个电机全部停止
PWM=0
PC0~PC5方向脚拉低
三个轴全部设置急停锁存
后续运动命令返回Result=5
```

急停回传停止事件：

```text
ID = 0x08C02184 + SEG偏移 + AXIS偏移
DLC = 2
DATA = 02 00
```

第1组机械臂1回传三帧：

```text
0x08C02184 DATA=02 00
0x08C02284 DATA=02 00
0x08C02384 DATA=02 00
```

## 7 解除急停

```text
ID：0x00000004
DLC：1
DATA：01
```

清除：

```text
全局急停锁存
电机1单轴急停锁存
电机2单轴急停锁存
电机3单轴急停锁存
```

不会清除：

```text
超位故障锁存
```

## 8 返回码判断

```text
Result=5 -> 先解除急停
Result=4 -> 再复位对应轴超位故障
Result=3 -> 检查目标参数
Result=2 -> 重新绑定组号和臂位
Result=1 -> 等待当前电机停止
```

## 9 推荐操作顺序

```text
1. 上电，接收UID宣告
2. 发送0x15BC0020绑定SEG和ARM
3. 检查0x15BC0050组号确认
4. 检查0x15BC0060臂位及AXIS确认
5. 可选发送0x00000020查询三电机状态
6. 发送运动命令并检查0x0480xx54 ACK
7. 接收0x08C0xx84停止事件
8. 接收0x08C0xx80到位事件
9. 超位时读取0x08C0xx90限位事件
10. 超位故障使用0x0440xx14复位
11. 模块急停使用0x00000004解除
```

## 10 当前限制

1. 每次上电都必须重新绑定SEG和臂位。
2. 同一SEG下5个机械臂必须使用不同ARM。
3. 编码器无进展和反向故障自动判断当前已关闭。
4. 当前轴故障锁存只由限位/超位保护触发。
5. TB6612没有电流、温度和nFAULT回读。
6. 同一时间三个电机仍然互斥运行。
